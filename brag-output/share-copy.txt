[LinkedIn]
I kept noticing the same invisible step before every AI prompt: copy the active file, copy the error, copy the git diff, trim it down, paste. The curation happens in your head, usually badly.

So I built Distyl, a VS Code extension that does it in one keystroke. It gathers from your active file, recent edits, git state, and terminal, ranks every chunk against your actual prompt using a local all-MiniLM-L6-v2 model, and greedily packs the highest scorers into a 4k/8k/16k token budget. Automatic selection reaches 87% overlap with context I curated by hand.

No API calls. Nothing leaves your machine.
